## 一、知识类型与组织方式（教学设计传统）

这一支是**本项目「按知识类型分骨架」的直接依据**：它回答的是「不同知识该怎么组织」，而不是「怎么教」。

### 1.1 Component Display Theory（CDT，成分显示理论）

- **提出者 / 年代**：M. David Merrill，1983；收于 Reigeluth 编 *Instructional-design theories and models*
- **领域**：教学设计
- **核心主张**：教学内容按两个维度分类——**内容类型**（事实 fact / 概念 concept / 程序 procedure / 原理 principle）× **表现水平**（记忆 remember / 运用 use）。不同类型、不同水平，要用不同的呈现策略。
- **结构与要素**：2×4 矩阵；每种组合对应一组教学呈现方式（讲解、例子、练习、反馈）。
- **本项目能用在哪里**：这是「按知识类型分骨架」的第一张映射表，也是「事实 → 清单型、概念与原理 → 体系型、程序 → 流程型」这一映射的来源。它同时提示：**类型决定呈现，而不是反过来**。
- **核实**：△

### 1.2 Elaboration Theory（精细化理论）

- **提出者 / 年代**：Charles M. Reigeluth，1979（*In search of a better way to organize instruction*）
- **领域**：教学设计
- **核心主张**：教学内容的组织顺序应按**知识自身的结构**，分三种组织方式——**概念性**（按概念之间的关系展开）、**程序性**（按步骤顺序展开）、**理论性**（按原理与因果展开）；顺序上先给**简化整体**（elaboration 的第一层），再逐层往细节精细化（zooming in）。
- **结构与要素**：三条组织规则 + 一条排序规则（整体 → 局部、简单 → 复杂）。
- **本项目能用在哪里**：① 支撑「主线应由知识结构决定，不由读者喜好决定」；② 支撑深度三档的实现顺序——**先给简化整体（一页入门），再逐层加细（全面了解、深入掌握）**，与已定的「一份内容 + 深度标记 + 三种视图」天然契合。
- **核实**：△（维基百科无独立条目）

### 1.3 4C/ID（Four-Component Instructional Design）

- **提出者 / 年代**：Jeroen van Merriënboer 等，1997 起，2002 定型（*Blueprints for complex learning*）
- **领域**：复杂技能的教学设计
- **核心主张**：复杂学习由四个组件支撑——**学习任务**（真实整体任务）、**支持性信息**（supportive information，回答「为什么、是什么」，用于非重复性技能）、**程序性信息**（procedural information，回答「怎么做」，用于重复性技能）、**部分任务练习**。
- **结构与要素**：四组件 + 任务类别 + 认知负荷调控规则。
- **本项目能用在哪里**：**支持性信息 vs 程序性信息的分野**，正是体系型 / 判断型与流程型的分界。它解释了为什么流程型页面不该塞进理论论述，也解释了判断型属于支持性信息、需要「为什么这么判」而不是「按哪一步做」。
- **核实**：△（维基百科无独立条目）

### 1.4 First Principles of Instruction（教学首要原理）

- **提出者 / 年代**：M. David Merrill，2002
- **领域**：教学设计
- **核心主张**：有效教学遵循五条原理——**问题 / 任务中心**（task-centered）、**激活**已有经验（activation）、**演示**（demonstration）、**应用**（application）、**整合**（integration）。
- **结构与要素**：五条原理构成一个循环，任务中心居于核心。
- **本项目能用在哪里**：① 支持**任务中心**的思路——主线判据应从「读者读完要做什么」出发，这与「读者合上页面后要做的第一件事」这一判据来源一致；② **激活**对应 A7 前置门槛与 A2 一页纸摘要的位置；③ **整合**对应 I5「学完能做什么」——入门路径必须有出口。
- **核实**：✓

### 1.5 Gagné 的九个教学事件

- **提出者 / 年代**：Robert M. Gagné，1965（*The Conditions of Learning*）
- **领域**：教学设计
- **核心主张**：教学是一串有顺序的事件——引起注意、告知目标、回忆旧知、呈现内容、提供指导、引发表现、给予反馈、评估表现、促进保持与迁移。
- **结构与要素**：九步序列，每步对应不同的学习条件。
- **本项目能用在哪里**：为**头部基线**的节序提供旁证（先给目标与定位，再给旧知衔接，再进主体）；也为尾部「促进保持与迁移」提供依据——对应 J9 相关主题与 J10 延伸问题。
- **核实**：✓（Gagné 条目存在）

### 1.6 陈述性知识 / 程序性知识

- **提出者 / 年代**：John R. Anderson，1976（*Language, Memory, and Thought*），后在 ACT-R 中形式化
- **领域**：认知心理学
- **核心主张**：知识分两类——**陈述性**（知道是什么，以命题网络存储）与**程序性**（知道怎么做，以产生式规则存储）；二者习得机制不同、调用方式不同。
- **结构与要素**：陈述性 → 程序化的转化过程（知识编译）。
- **本项目能用在哪里**：体系型 / 流程型分野的认知科学根基；也提示「同一个主题在两种知识层面上的组织方式本就不同」，属于**不可用同一骨架强行统一**的硬理由。
- **核实**：△

### 1.7 认知负荷理论（Cognitive Load Theory）

- **提出者 / 年代**：John Sweller，1988
- **领域**：教育心理学
- **核心主张**：工作记忆容量有限，学习负担分三类——**内在负荷**（内容本身的复杂度）、**外在负荷**（呈现方式带来的额外负担）、**相关负荷**（用于构建图式的有效负担）。外在负荷可直接削减。
- **结构与要素**：三类负荷 + 一系列削减外在负荷的手段（示例效应、分块、避免割裂注意）。
- **本项目能用在哪里**：① 为页面的**导航、编号、检索、目录、折叠**正名——它们是**削减外在负荷**的手段，不是装饰；② 为「一页入门」视图的存在提供依据：初学者内在负荷高，需要更少的并行信息。
- **核实**：✓（Cognitive load、John Sweller 条目存在；Worked-example effect 亦存在）

### 1.8 先行组织者（Advance Organizer）

- **提出者 / 年代**：David Ausubel，1960
- **领域**：教育心理学
- **核心主张**：在正式学习内容之前提供一段**上位的、概括性的**框架，能显著改善理解与保持——前提是它必须比正文更抽象、更概括，而不是正文的摘要复述。
- **结构与要素**：先行组织者（说明性 / 比较性两类）+ 正文 + 下位内容。
- **本项目能用在哪里**：**A2 一页纸摘要的位置与性质**——必须在所有细节之前，且必须是上位的（讲这套知识整体怎么组织），而不是把后面的内容压缩一遍。这条可以用来检验 A2 是否写跑偏。
- **核实**：△

### 1.9 图式理论（Schema Theory）

- **提出者 / 年代**：Frederic Bartlett，1932；Rumelhart 等在 1970–80 年代形式化
- **领域**：认知心理学
- **核心主张**：知识以**图式**（有组织的知识单元）形式存储；理解新信息＝把它挂到已有图式上，或调整图式去容纳它。
- **结构与要素**：图式的激活、同化、顺应。
- **本项目能用在哪里**：解释为什么「知识地图」必须给出**关系**而不只是名词——读者需要的是可以挂载的骨架；也解释了前置门槛（A7）的作用：没有可挂载的图式，后面的内容会无处安放。
- **核实**：△

### 1.10 概念转变理论（Conceptual Change）

- **提出者 / 年代**：Posner、Strike、Hewson、Gertzog，1982
- **领域**：科学教育
- **核心主张**：要让学习者放弃错误概念，需要四个条件——对现有概念**不满意**、新概念**可理解**、**貌似合理**、**有效用**。
- **结构与要素**：四条件 + 认知冲突的设计。
- **本项目能用在哪里**：**E8 常见误区与陷阱**的写法依据——只罗列「常见错误说法」不足以改变认知，必须给出「为什么错」和「更准确的理解」（分别对应「不满意」和「貌似合理」两个条件）。
- **核实**：△

## 二、认知层次与深度

### 2.1 Bloom 认知层次（Bloom's Taxonomy）

- **提出者 / 年代**：Benjamin Bloom 等，1956；Anderson & Krathwohl 修订，2001
- **领域**：教育目标分类
- **核心主张**：认知目标分六个层次——**记忆 → 理解 → 应用 → 分析 → 评价 → 创造**（修订版把名词改为动词，并增加「元认知知识」维度）。
- **结构与要素**：六层阶梯；低层是高层的前提，但不是必须逐层走完。
- **本项目能用在哪里**：**深度三档的学术依据**——一页入门 ≈ 理解层，全面了解 ≈ 分析层，深入掌握 ≈ 评价与创造层。挂上之后，「这三档分别该写到什么程度」才有可判定的说法，而不是凭感觉。
- **核实**：✓

### 2.2 SOLO 分类（Structure of Observed Learning Outcomes）

- **提出者 / 年代**：John Biggs & Kevin Collis，1982
- **领域**：教育评价
- **核心主张**：学习结果按**结构复杂度**分五级——前结构（答非所问）、单点（只抓一个点）、多点（罗列多个点但互不关联）、关联（能建立关系）、抽象扩展（能推广到新情境）。
- **结构与要素**：五级结构，判据是「点与点之间有没有关系」。
- **本项目能用在哪里**：比 Bloom 更适合检验**内容质量**——「多点」就是罗列名词的浅产出，「关联」才是我们要的；可用作 E8 之外的通用质量尺，判断一段内容是不是只堆了信息没给关系。
- **核实**：△

### 2.3 DIKW 金字塔

- **提出者 / 年代**：概念渊源可追至 T. S. Eliot，常归于 Russell Ackoff，1989
- **领域**：知识管理 / 信息科学
- **核心主张**：数据 → 信息 → 知识 → 智慧，逐层加值：数据是原始符号，信息是有上下文的数据，知识是能指导行动的信息，智慧是知道何时用哪种知识。
- **结构与要素**：四层金字塔（也有链式表述）。
- **本项目能用在哪里**：与深度三档互相印证；也用来提醒：**只给数值（数据）而不给判读口径（知识）的页面不合格**——这直接支持 H1 / H2 数据类模块必须附带「怎么读」的要求。
- **核实**：✓

### 2.4 理解的六个侧面（Understanding by Design）

- **提出者 / 年代**：Grant Wiggins & Jay McTighe，1998
- **领域**：课程设计
- **核心主张**：真正的理解有六个侧面——能**解释**、能**释义**、能**应用**、有**视角**、能**共情**、能**自知**。
- **结构与要素**：六侧面（常缩写为 six facets）。
- **本项目能用在哪里**：给 A2 一页纸摘要的「能独立阅读」提供了可检验的维度；也支持在体系型里保留「争议与不同学派视角」（F4）——「有视角」是理解的一部分。
- **核实**：△

## 三、记忆、练习与迁移

这一支与项目的直接关系较弱（本项目不做持续教学闭环），但影响**深度标记的设计**与**自测题模块（I2）的写法**。

### 3.1 间隔重复（Spaced Repetition）

- **提出者 / 年代**：Hermann Ebbinghaus，1885（遗忘曲线）；现代实现如 SM-2 算法（Wozniak，1987）
- **领域**：记忆心理学
- **核心主张**：在即将遗忘时复习，记忆保持率最高；分散复习优于集中复习。
- **本项目能用在哪里**：**已排除**——本项目不做学习打卡与复习调度。但这条解释了「为什么个人速查手册仍有需求」：它充当**外部记忆**，替代了部分复习需求。
- **核实**：△

### 3.2 提取练习 / 测试效应（Retrieval Practice, Testing Effect）

- **提出者 / 年代**：Henry Roediger & Jeffrey Karpicke，2006
- **领域**：认知心理学
- **核心主张**：主动回忆比重复阅读更能形成长期记忆。
- **本项目能用在哪里**：**I2 自测题**的存在依据；也说明自测题不能只问「是什么」，要用能触发回忆的形式（给场景问判据、给数值问含义）。
- **核实**：△

### 3.3 交错练习（Interleaving）

- **提出者 / 年代**：Rohrer & Taylor，2007 等
- **领域**：学习科学
- **核心主张**：把不同类型的题目混着练，比按类型集中练效果更好（尽管当下感觉更难）。
- **本项目能用在哪里**：**C4 易混淆概念辨析**与 **F2 反例**的组织依据——把相近概念并排放在一起，制造需要辨别的情境。
- **核实**：△

### 3.4 刻意练习（Deliberate Practice）

- **提出者 / 年代**：K. Anders Ericsson，1993
- **领域**：专长研究
- **核心主张**：有效练习需要明确目标、即时反馈、走出舒适区、针对弱点。
- **本项目能用在哪里**：**I2 自测题的答案必须给「为什么」**（即时反馈），而不能只给对错。
- **核实**：△

### 3.5 迁移（近迁移 / 远迁移）

- **提出者 / 年代**：学习科学通说，源自 Thorndike 等
- **领域**：教育心理学
- **核心主张**：近迁移（相似情境间）容易，远迁移（跨领域）难；抽象出结构比记表面特征更有助于迁移。
- **本项目能用在哪里**：**J8 跨学科关联**与 **I5 学完能做什么**的写法依据——能力承诺应写成可迁移的结构性能力，而不是绑定具体例子。
- **核实**：△

### 3.6 经验学习圈（Experiential Learning Cycle）

- **提出者 / 年代**：David Kolb，1984
- **领域**：学习理论
- **核心主张**：学习是循环——具体经验 → 反思观察 → 抽象概念化 → 主动实验。
- **本项目能用在哪里**：流程型与判断型的**实践回路**写法：给出一个流程后，应留下「跑一遍 → 看结果 → 调参数」的闭环描述。
- **核实**：△

### 3.7 生成学习 / 精加工（Generative Learning, Elaboration）

- **提出者 / 年代**：Merlin Wittrock，1974
- **领域**：教育心理学
- **核心主张**：学习者主动生成联系与解释（而不是被动接收）时，理解更深。
- **本项目能用在哪里**：支持**把定义与例子绑定**的写法——术语卡除定义外必须给展开与例子，就是在替读者做生成。
- **核实**：△

### 3.8 双重编码理论（Dual Coding）

- **提出者 / 年代**：Allan Paivio，1971
- **领域**：认知心理学
- **核心主张**：语言系统与图像系统分别编码，两者并用时记忆与理解更好。
- **本项目能用在哪里**：支持知识地图、时间轴、分层图这类**图形化模块**的必要性——它们不是装饰，是另一条编码通道。
- **核实**：△

## 四、检索、信息架构与知识组织

### 4.1 信息觅食理论（Information Foraging）

- **提出者 / 年代**：Peter Pirolli & Stuart Card，1999
- **领域**：人机交互 / 信息科学
- **核心主张**：人在信息环境中的行为类似动物觅食——沿**信息气味**（information scent，链接或标题透露出的线索强度）最浓的路径前进，追求收益 / 代价比最大。
- **结构与要素**：信息气味、觅食路径、信息斑块（patch）。
- **本项目能用在哪里**：**清单型主线的第一判据是「找得到」**。分类、标签、索引、条目标题的作用都是提高信息气味；标题写得含糊就是气味丢失。
- **核实**：✓

### 4.2 意义建构（Sense-Making）

- **提出者 / 年代**：Brenda Dervin，1983 起
- **领域**：信息行为研究
- **核心主张**：信息需求产生于「情境 → 缺口 → 使用」的三角；用户带着一个**缺口**来查信息，而不是来通读。
- **本项目能用在哪里**：判断型与清单型页面的入口设计——开头应点明「你可能会在什么处境下来查这一页」。
- **核实**：△

### 4.3 最小努力原则（Principle of Least Effort）

- **提出者 / 年代**：George Zipf，1949
- **领域**：语言学 / 信息行为
- **核心主张**：信息寻求者倾向选择最省力的路径，即使结果质量更低。
- **本项目能用在哪里**：支持**页内检索、目录、锚点、折叠**这类「低摩擦」设计的优先性；也提醒内容不能被埋在长页深处。
- **核实**：△

### 4.4 概念图（Concept Map）

- **提出者 / 年代**：Joseph Novak，1972 起（基于 Ausubel 的有意义学习理论）
- **领域**：教育 / 知识表征
- **核心主张**：知识用**概念节点 + 带标签的连接关系**表示，一条「概念—连接词—概念」构成一个**命题**；层级结构体现概括程度。
- **结构与要素**：节点、带标签的连线、层级、交叉连接。
- **本项目能用在哪里**：**知识地图必须给关系，不能给散点**。「节点 + 标注关系」是形态要求；也提示地图应体现层级（哪些是上位概念）。
- **核实**：✓

### 4.5 语义网络（Semantic Network）

- **提出者 / 年代**：Ross Quillian，1968
- **领域**：认知科学 / 人工智能
- **核心主张**：概念以网络形式存储，语义关系（is-a、part-of 等）沿边扩散激活。
- **本项目能用在哪里**：术语卡的字段设计依据——除了定义，应给出它的**上下位与组成关系**（属于什么、包含什么）。
- **核实**：△

### 4.6 本体论 / 知识图谱（Ontology / Knowledge Graph）

- **提出者 / 年代**：Thomas Gruber，1993（本体论定义）；知识图谱流行于 2012 后
- **领域**：知识工程
- **核心主张**：一个领域可以用**类、属性、关系、实例**四要素形式化描述。
- **本项目能用在哪里**：模块规格卡的字段设计思路（一条内容＝一个实例，字段＝属性）；也用于定义**术语条目的最小字段集**。
- **核实**：△

### 4.7 分面分类（Faceted Classification）

- **提出者 / 年代**：S. R. Ranganathan，1933（冒号分类法）
- **领域**：图书馆学
- **核心主张**：与其把条目塞进一棵单一的分类树，不如给它打上**多个独立维度**的标签（分面），检索时靠维度组合筛选。
- **本项目能用在哪里**：**用户已定的分型口径「领域作标签、性质作骨架」正是分面思想的直接应用**；也支持术语卡带 `tier`、主题、属性等多个筛选维度。
- **核实**：△

### 4.8 信息架构的四系统

- **提出者 / 年代**：Louis Rosenfeld & Peter Morville，1998（*Information Architecture for the World Wide Web*）
- **领域**：信息架构
- **核心主张**：网站的信息架构由四套系统组成——**组织系统**（怎么分类）、**标签系统**（怎么命名）、**导航系统**（怎么走）、**搜索系统**（怎么找）。
- **本项目能用在哪里**：**清单型主线「分类 → 索引 → 条目 → 判读」正好对应这四系统**；也是页面结构合格性的一个自检清单。
- **核实**：△

### 4.9 渐进式披露（Progressive Disclosure）

- **提出者 / 年代**：交互设计通说，1990 年代起广泛使用
- **领域**：交互设计
- **核心主张**：默认只显示主信息，次要信息按需展开，降低初始认知负担。
- **本项目能用在哪里**：① 深度三档视图的实现手段；② 折叠卡、悬停展开等交互的正当性依据；③ **不可摘要化的模块例外**——条目表、时间轴、判据表不能折叠掉主体。
- **核实**：△

### 4.10 记忆术与助记（Mnemonics）

- **提出者 / 年代**：渊源古远；现代研究见 Bower、Bellezza 等
- **领域**：记忆心理学
- **核心主张**：把无意义信息挂到熟悉结构上（口诀、首字母、位置法）可显著提高回忆率。
- **本项目能用在哪里**：清单型与体系型中的**分类口诀**（如营养素的分类顺口溜）；但要注意不能以助记替代理解。
- **核实**：△

## 五、决策与判断

### 5.1 决策分析（Decision Analysis）

- **提出者 / 年代**：Howard Raiffa，1968（*Decision Analysis*）；决策科学作为学科 1960 年代成形
- **领域**：运筹学 / 决策科学
- **核心主张**：重大决策应被形式化：明确目标、列出备选方案、量化不确定性与偏好、算出期望效用，再做敏感性分析。
- **本项目能用在哪里**：**判断型主线的整体框架**——「判据 → 阈值 → 反面 → 风险 → 结论」就是决策分析的简化版；它要求判断型页面不能停在「要考虑哪些因素」。
- **核实**：✓

### 5.2 多准则决策分析（MCDA / MCDM）与 AHP

- **提出者 / 年代**：MCDA 1970 年代成形；AHP 由 Thomas Saaty 于 1970 年代提出
- **领域**：运筹学
- **核心主张**：多准则决策要显式给出**准则、权重、评分与阈值**，并通过敏感性分析检验结论稳健性。
- **本项目能用在哪里**：**判断型页面必须给权重与阈值**，否则只是「考虑因素清单」。这是判断型与清单型最容易混淆的地方，也是最该写死的硬要求。
- **核实**：✓

### 5.3 期望效用与决策树

- **提出者 / 年代**：von Neumann & Morgenstern，1944（期望效用）；决策树广泛应用于 1960 年代后
- **领域**：决策理论
- **核心主张**：把决策画成分支树，每条路径给概率与结果，回溯计算期望值。
- **本项目能用在哪里**：**B6 决策分叉**的呈现原型（分支图而非文字流程）；也用于判断型入口的写法——先问「你在哪个岔路口」。
- **核实**：△

### 5.4 双系统理论（System 1 / System 2）

- **提出者 / 年代**：Daniel Kahneman，2011（*Thinking, Fast and Slow*），理论内核与其 1970 年代起的工作相关
- **领域**：行为经济学
- **核心主张**：系统 1 快速、自动、直觉；系统 2 缓慢、费力、理性。多数判断偏差源于系统 1 在没有被系统 2 检查时接管。
- **本项目能用在哪里**：**F2 反例**与 **F3 风险 / 误判代价**的存在理由——它们的作用就是在读者用系统 1 得结论时，提供一次系统 2 的检查点。
- **核实**：△

### 5.5 前景理论（Prospect Theory）

- **提出者 / 年代**：Kahneman & Tversky，1979
- **领域**：行为经济学
- **核心主张**：人对损失的敏感度高于等量收益；面对收益倾向风险规避，面对损失倾向风险偏好。
- **本项目能用在哪里**：**判断型「误判代价 / 可逆性 / 退出成本」字段**的依据——损失厌恶意味着「错了能不能退」比「对了值多少」更需要写清楚。
- **核实**：△

### 5.6 Cynefin 框架

- **提出者 / 年代**：Dave Snowden，1999（在 IBM 期间）
- **领域**：知识管理 / 决策
- **核心主张**：把处境分四类——**简单**（known，最佳实践）、**繁杂**（knowable，专家分析）、**复杂**（complex，探针试验）、**混沌**（chaotic，先行动止血）；不同处境适用不同的决策方式，误判处境是最大的错误。
- **结构与要素**：四象限 + 中心「失序」区；后来加入第五域「混乱 / 困惑」。
- **本项目能用在哪里**：**类型判定的现成思路**——此前验收报告 P0-6 指出「类型判定与混合型叠加无规则」。它的定式是「**先看处境，再定方法**」，与本项目「先判类型，再选骨架」同构。也提示：类型判定应当**先问读者要做什么、这个知识处于什么成熟度**，而不是先看主题名字。
- **核实**：✓

### 5.7 OODA 循环

- **提出者 / 年代**：John Boyd，1976 起
- **领域**：军事战略 / 决策
- **核心主张**：决策循环——观察（Observe）→ 定向（Orient）→ 决策（Decide）→ 行动（Act）；快速循环并扰乱对手循环即获得优势。
- **本项目能用在哪里**：判断型的**迭代特征**——判据不是一次性的，页面应写明「多久复核一次判据」（对应 F1 的「数据时点」字段）。
- **核实**：△

### 5.8 贝叶斯推理与基率谬误

- **提出者 / 年代**：贝叶斯定理 1763；认知偏差研究见 Tversky & Kahneman，1973 起
- **领域**：统计学 / 认知心理学
- **核心主张**：先验概率 + 新证据 → 后验概率；忽略基率是常见错误。
- **本项目能用在哪里**：**F1 判据表必须给「数据时点」与背景概率**，否则读者会把一次观测当成全局规律。
- **核实**：△

### 5.9 预验尸（Pre-mortem）

- **提出者 / 年代**：Gary Klein，2007（*Performing a Project Premortem*）
- **领域**：决策支持
- **核心主张**：在决策前假定「这事已经失败了」，再倒推失败原因，能显著提高风险识别率。
- **本项目能用在哪里**：**F3 风险**与 **E8 误区**的写法——与其问「有什么风险」，不如先设定失败场景再找原因。
- **核实**：△

## 六、时间、因果与叙事

### 6.1 三时段 / 长时段（Longue durée）

- **提出者 / 年代**：Fernand Braudel，1958（年鉴学派）；与 François Simiand 提出的「事件史」相对
- **领域**：历史学
- **核心主张**：历史时间分三层——**结构**（长时段，地理与经济结构，以百年计）、**局势**（中时段，周期与趋势，以十年计）、**事件**（短时段，以日计）；只讲事件是「事件史」，看不到结构。
- **本项目能用在哪里**：**史实型的时间轴应分层**——D2 分期（结构层）与 D1 历史脉络（事件层）不是重复，而是不同时间尺度。这条同时解释了为什么不写成一条平铺的时间线。
- **核实**：✓

### 6.2 覆盖律模型（Covering Law Model）

- **提出者 / 年代**：Carl Hempel，1942
- **领域**：科学哲学 / 历史哲学
- **核心主张**：解释一个事件＝把它归入普遍规律，并说明初始条件。只描述「前后发生」不是解释。
- **本项目能用在哪里**：**D6 因果分析**的写法——「为什么是转折」必须给**机制**，不能只写「A 之后发生了 B」；也用于验收：凡是写「因为……所以……」却给不出机制的地方，视为未达标。
- **核实**：△

### 6.3 路径依赖（Path Dependence）

- **提出者 / 年代**：Paul David，1985（QWERTY 键盘）；W. Brian Arthur 同期工作
- **领域**：经济史
- **核心主张**：早期的小事件通过正反馈锁定长期结果，导致「不是最优的选项胜出」。
- **本项目能用在哪里**：史实型与技术类体系型中的**「为什么今天的标准是它」**类问题（如 HTTP/2、键盘布局、法规条款），是「历史脉络」与「判断型」的交叉点。
- **核实**：△

### 6.4 反事实推理（Counterfactual Reasoning）

- **提出者 / 年代**：历史学与统计因果推断中的通行方法（后者见 Rubin 因果模型，1970s）
- **领域**：历史学 / 因果推断
- **核心主张**：通过设想「如果没有 X 会怎样」来评估某因素的实际作用。
- **本项目能用在哪里**：**F4 共识与争议**中的「另一种解释」；也用于史实型 D6：区分「必要因素」与「背景条件」。
- **核实**：△

### 6.5 叙事结构与五幕（Freytag's Pyramid）

- **提出者 / 年代**：Gustav Freytag，1863
- **领域**：文学 / 叙事学
- **核心主张**：经典叙事有五段——铺陈、上升、高潮、下降、收束。
- **本项目能用在哪里**：**史实型主线的顺序旁证**——「背景 → 分期 → 事件 → 因果 → 影响」与叙事的张力曲线同构；但注意史实型不得为了好看而制造戏剧性，评价必须与事实分开。
- **核实**：△

### 6.6 案例研究法（Case Study Method）

- **提出者 / 年代**：Robert K. Yin，1984（*Case Study Research*）
- **领域**：社会科学方法
- **核心主张**：案例研究适合回答「怎么发生」「为什么」的问题；要求明确分析单位、多来源证据、与理论命题对照。
- **本项目能用在哪里**：**J7 应用案例**与 **F2 反例**的写法——案例必须写清分析单位（一个组织？一个项目？一次事故？）与证据来源，否则就是故事。
- **核实**：△

## 七、系统与复杂性

### 7.1 系统思维与因果回路图（Causal Loop Diagram）

- **提出者 / 年代**：Jay Forrester，1961（系统动力学）；Peter Senge，1990（*The Fifth Discipline*）普及
- **领域**：系统科学 / 组织学习
- **核心主张**：系统行为由要素之间的反馈回路决定，而非单条因果链；因果回路图用带极性（+/-）的有向边表示反馈。
- **本项目能用在哪里**：**体系型中的循环关系**（如营养素之间的相互作用、生态与政策）无法用「依赖链」表达，需要回路图；也是知识地图的一种形态。
- **核实**：△

### 7.2 反馈回路：增强回路与平衡回路

- **提出者 / 年代**：系统动力学基本概念
- **领域**：系统科学
- **核心主张**：回路分两类——增强（正反馈，自我放大，指数增长或崩溃）与平衡（负反馈，自我修正，趋向目标）。
- **本项目能用在哪里**：体系型与判断型中的**动态描述**——很多「越……越……」的论断其实是回路，写成线性因果是错的。
- **核实**：△

### 7.3 涌现与复杂适应系统

- **提出者 / 年代**：John Holland 等，1990 年代
- **领域**：复杂性科学
- **核心主张**：系统整体行为由大量局部互动涌现而来，不能被分解为个体属性之和。
- **本项目能用在哪里**：**体系型的边界声明（A6）**——说明「这类知识不能靠拆解单个要素理解」，反过来界定本页能讲什么、不能讲什么。
- **核实**：△

### 7.4 冰山模型（系统的层次）

- **提出者 / 年代**：系统思维实务中的常用模型（事件 → 模式 → 结构 → 心智模型）
- **领域**：组织发展
- **核心主张**：看到事件之下的**模式**、模式之下的**结构**、结构之下的**心智模型**，才算理解系统。
- **本项目能用在哪里**：与 Braudel 的时段分层呼应；也可用于**深度三档**的另一种解释——入门看事件，全面看结构，深入看心智模型。
- **核实**：△

## 八、通用思维工具

这一节是**内容组织与表达**的通用工具，未必进骨架，但会影响模块内部怎么写。

### 8.1 第一性原理（First Principles Thinking）

- **提出者 / 年代**：亚里士多德的概念；现代实务化常归于 Elon Musk 的表述
- **领域**：通用思维
- **核心主张**：把问题拆到不可再分的基本事实，再自下而上重建，而不是照搬类比。
- **本项目能用在哪里**：**体系型「核心理论」模块的写法**——先给基本假设与公理，再给由它们推出的结论；而不是直接罗列「几大理论」。
- **核实**：△

### 8.2 MECE 与金字塔原理（Pyramid Principle）

- **提出者 / 年代**：Barbara Minto，1987（麦肯锡）；MECE 为同期通说
- **领域**：商业沟通
- **核心主张**：论述应「结论先行，以上统下，归类分组，逻辑递进」；分类要相互独立、完全穷尽（MECE）。
- **本项目能用在哪里**：**A2 一页纸摘要**与**各个分类模块**的结构检验——分类不 MECE 是常见缺陷（如术语分类既有「按性质」又有「按用途」，混在一起）。
- **核实**：△

### 8.3 5W1H / 六何分析法

- **提出者 / 年代**：新闻学传统，1930 年代起
- **领域**：通用
- **核心主张**：完整描述一件事要回答六个问题——What / Why / Who / When / Where / How。
- **本项目能用在哪里**：**A1 一句话定位与 A6 边界声明**的写作检查表；也用于「重要人物与学派」（D4）的字段设计（Who / When / Where / 贡献）。
- **核实**：△

### 8.4 SWOT / PEST / 波特五力

- **提出者 / 年代**：SWOT 1960 年代（Learned 等）；PEST 通说；波特五力 1979
- **领域**：战略分析
- **核心主张**：分别从内部与外部、宏观与行业的结构化维度做处境扫描。
- **本项目能用在哪里**：**判断型 F6 处境扫描**的模板；也提醒这类框架只提供「扫描维度」，给出结论仍需判据与阈值——正好作为 F1 不可省略的反证。
- **核实**：△

### 8.5 第二序思维（Second-Order Thinking）

- **提出者 / 年代**：Howard Marks，2011（《投资最重要的事》）
- **领域**：投资 / 决策
- **核心主张**：不只问「这个行动会导致什么」，还要问「别人会怎么反应、长期会怎样」。
- **本项目能用在哪里**：**判断型 F3 风险**中的「二阶后果」字段；也是判断型与清单型拉开差距的地方。
- **核实**：△

### 8.6 六顶思考帽（Six Thinking Hats）

- **提出者 / 年代**：Edward de Bono，1985
- **领域**：思维方法
- **核心主张**：把思考按角色分开并行——事实、感受、风险、收益、创意、流程。
- **本项目能用在哪里**：**F4 共识与争议**的组织方式——把「事实层共识」与「价值层分歧」分开陈述，避免像在评价谁对谁错。
- **核实**：△

### 8.7 类比与结构映射（Structure Mapping）

- **提出者 / 年代**：Dedre Gentner，1983
- **领域**：认知科学
- **核心主张**：类比的价值在于**关系结构**的对应，而非表面属性的相似；好的类比能迁移推理。
- **本项目能用在哪里**：**J8 跨学科关联**与**举例说明**的质量判据——「就像……一样」必须给出结构对应，否则是无效类比。
- **核实**：△

## 九、元认知与反思

### 9.1 元认知（Metacognition）

- **提出者 / 年代**：John Flavell，1979
- **领域**：发展心理学
- **核心主张**：元认知包括**元认知知识**（知道自己知道什么）与**元认知调节**（计划、监控、评估自己的学习）。
- **本项目能用在哪里**：**I5「学完能做什么」**的另一种表述视角——它本质上是让读者能自我评估；也支持 I2 自测题应给出「答错了说明什么」。
- **核实**：△

### 9.2 自我调节学习（Self-Regulated Learning）

- **提出者 / 年代**：Barry Zimmerman，1989
- **领域**：教育心理学
- **核心主张**：学习是「计划 → 执行 → 自我反思」的循环，受目标设定与自我效能影响。
- **本项目能用在哪里**：**I1 学习路线图 + I5 出口**的组合逻辑——路线图规划，出口提供反馈。
- **核实**：△

### 9.3 反思性实践（Reflective Practice）

- **提出者 / 年代**：Donald Schön，1983（*The Reflective Practitioner*）
- **领域**：专业教育
- **核心主张**：专业能力来自「行动中反思」与「对行动的反思」。
- **本项目能用在哪里**：**J10 延伸问题**的设计——好的延伸问题是能引发反思的问题（「如果换个前提，结论还成立吗」），而不是「还有哪些相关内容」。

## 十、与本项目的映射

### 10.1 五类主线 × 主要依据

| 类型 | 组织主线 | 主要依据 |
| --- | --- | --- |
| 体系型 | 概念依赖链（是什么 → 由哪些概念支撑 → 如何依赖 → 边界 → 怎么演化） | CDT（概念 / 原理）+ Elaboration Theory（概念性）+ 4C/ID（支持性信息）+ 概念图 + 陈述性知识 + 图式理论 |
| 流程型 | 操作时序（准备 → 执行 → 验证 → 排错） | CDT（程序）+ Elaboration Theory（程序性）+ 4C/ID（程序性信息）+ 程序性知识 + 经验学习圈 |
| 清单型 | 查阅动线（分类 → 索引 → 条目 → 判读） | 信息觅食理论 + 信息架构四系统 + 分面分类 + CDT（事实）+ 最小努力原则 |
| 判断型 | 决策链（目标 → 判据 → 阈值 → 反面 → 风险 → 结论） | 决策分析 + MCDA / AHP + 4C/ID（支持性信息）+ 双系统理论 + 前景理论 + 预验尸 |
| 史实型 | 时间与因果（背景 → 分期 → 事件 → 因果 → 影响） | Braudel 三时段 + Hempel 覆盖律 + 路径依赖 + 反事实推理 + 叙事学 |

### 10.2 两条支流（重要）

映射表里藏着两件不同来源的事，正式文档里应分开标注：

- **体系型 / 流程型 / 史实型**的主线由**知识自身的组织结构**决定——依据是教学设计传统（CDT、Elaboration Theory、4C/ID）与史学传统。
- **清单型 / 判断型**的主线由**使用任务类型**决定——依据是信息行为研究（信息觅食、信息架构）与决策科学（决策分析、MCDA）。

这不是拼凑：学界本就是「内容类型」与「任务类型」两支传统。但混在一张表里会显得不整齐，正式表述中应说明来源。

### 10.3 已可直接引用的设计结论

1. **深度三档挂 Bloom**：一页入门 = 理解，全面了解 = 分析，深入掌握 = 评价与创造。
2. **判断型必须给权重与阈值**（MCDA）：否则只是「考虑因素清单」，这与清单型没有区别。
3. **史实型时间轴应分层**（Braudel）：D2 分期是结构层，D1 历史脉络是事件层，二者不是重复。
4. **A2 一页纸摘要必须是上位框架**（Ausubel）：不是把正文压缩一遍，而是讲整体怎么组织。
5. **知识地图必须给关系**（概念图 + 图式理论）：节点 + 带标签的连线，不是名词列表。
6. **因果必须给机制**（Hempel）：只写「A 之后 B」不算解释。
7. **E8 误区必须给「为什么错」**（概念转变理论）：只列错误说法不改变认知。
8. **导航 / 检索 / 目录是认知负荷手段**（Sweller）：不是装饰，是可验收项。
9. **类型判定可借鉴 Cynefin**：先看处境与读者任务，再定骨架，而不是先看主题名。
10. **内容质量的通用尺可用 SOLO**：「多点」是浅产出（罗列无关系），「关联」才是目标。

## 十一、待补与排除

### 11.1 待补

- **叙事学**：本项目只收了 Freytag 五幕，若史实型要深入，可补 Propp、Genette 的叙事结构研究。
- **知识表征的图形语法**：如何选图（层级图 / 网络图 / 时间轴 / 矩阵）尚无依据，可查图形语法与可视化分类学（如 Bertin 的视觉变量、Munzner 的 *Visualization Analysis and Design*）。
- **信息检索的评价指标**：精确率 / 召回率等，若将来做收纳端检索会用到。
- **中文语境的知识分类传统**：目前全为西方理论，可补《七略》《四库全书总目》等中文分类传统的思路，以及现代中文教材的知识组织惯例。
- **教材与工具书的编写规范**：辞书条目写法（如《中国大百科全书》的条目体例）对本项目的「术语卡 / 条目表」有直接参考价值，待补。

### 11.2 已排除（记录理由，免得重复考虑）

| 框架 | 排除理由 |
| --- | --- |
| SECI 模型（Nonaka & Takeuchi，1995） | 面向组织内隐性知识与显性知识的转化，本项目是单人查阅场景，不适用 |
| 间隔重复调度算法 | 项目不做学习闭环与复习提醒；已由「深度三档视图」替代 |
| 翻转课堂 / 混合式学习等教学模式 | 涉及教学过程，与「一次性产出静态页面」的定位不符 |
| 学习风格理论（VARK 等） | 学界对其有效性争议大，不采纳为此类设计依据 |
